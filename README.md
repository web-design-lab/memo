# 個別スポットレッスン・制作サポート

学校の課題や個人の制作、独学で「自力だと時間がかかりそう」「ここだけ教えてほしい」という時に利用できる単発サポートのご案内です。

## サポート内容の例

- デザインツールの操作フォロー（Illustrator / Photoshop 等）
- Web制作・課題制作のコード確認（HTML / CSS 等）
- ショートカットやPC基本操作の効率化・スピードアップ
- 「どこから手をつければいいかわからない」場合の進め方整理

## 実施形式

- **1回完結の単発利用**（必要な時だけご相談いただければOKです）
- 入会金・月謝制・継続の縛り等はありません

## 場所・日程

- **場所：** 駅周辺のコワーキング・カフェ・レンタルスペース等（応相談）
- **日程：** 土日祝または平日夕方以降など、空きスケジュールで事前調整

## ご相談・お問い合わせ

「この課題の進め方だけ聞きたい」「操作のコツを知りたい」など、ご相談はInstagramのDMよりお気軽にご連絡ください。
